平台说明
================================================================================
1）导入ETMCU.ET6039_DFP.0.2.4.pack
2）使用MDK打开工程，兼容AC5和AC6编译器，-O3优化
3）ET6039系统时钟固定为200MHz，以保持16kHz PWM和500ns死区参数不变

功能描述
================================================================================
本工程是基于正点原子ATK-PD6010B 驱动板和42JSF6310AS-1000 PMSM电机实现基于空间矢量调制的FOC驱动，实现电机的速度控制
可使用按键进行速度调节，KEY1->+按步进值；KEY2->-步进值（正值：逆时针旋转，负值：顺时针旋转）；
工程中提供速度闭环操作模式，可实现最低300RPM到3000RPM速度调节
可使用ST的MCSDK 5.4.4调试工具进行数据信息查看及PID参数调节，或者直接采用MDK的debug模式进行在线调试
================================================================================

---------------------

---------------------
示波器
直流电源

---------------------

================================================================================
使用步骤
================================================================================
1）打开工程并重新编译;
2）确保硬件连接正确，电源电压稳定；
3）全速运行样例代码;
4）观察LED4是否闪烁；
5）按下按键KEY1或KEY2进行速度调节；
6）观察电机是否旋转；
7）打开ST调试助手，查看数据信息或进行参数调节。
8）驱动板硬件保护时，按SW3ET_RST复位控制板


================================================================================
注意
================================================================================
无感FOC硬件使用排线连接ETEB-6039PV-V1的J10与ATK-PD6010B控制&采集接口，
并正确连接驱动板电源及三相电机UVW端口。首次上电前应先断开电机功率电源，
检查六路PWM的相序、互补关系和死区时间。
